# Картинки для лонгрида

Загрузи файлы в эту папку **ровно с такими именами** (формат `.jpg`). Как только файл появится, он сам встанет на место заглушки; пока файла нет — остаётся заглушка.

| Файл | Где на странице | Пропорции |
|---|---|---|

Все картинки уже встроены в страницу — загружать сюда ничего не нужно. Механизм остался: файл с именем из `data-img` заменит заглушку, если она появится. Флешка и скриншот iamtryingtobelieve.com тоже уже встроены. Фото группы в начале тоже уже встроены. Оба слоя Another Version of the Truth тоже уже встроены. Флаг Art Is Resistance уже встроен в страницу. Две студийные фотографии после «…являлся их создателем.» уже встроены в страницу, их загружать не нужно. Пропорции — ориентир: картинка обрезается по центру под рамку, так что подойдёт и чуть другой формат. Удобный размер — 1600 px по длинной стороне.
