# Y34RZ3R0 · «Проявка»

Interactive longread about Nine Inch Nails' *Year Zero* (2007): where does an album end when its story continues through websites, objects, hidden messages and the audience?

- **Page:** `index.html` — a single self-contained file (HTML + CSS + JS). Open it in a browser, or via GitHub Pages.
- **Docs:** `docs/` — design notes, motion and typography research, and the change spec for every round (`docs/changes/v04.md` … `v10.md`).

## Status
Work in progress. Still placeholders: archival photos, the Art Is Resistance image, song-lyric lines, band photos, video frames, sources list.

## Stack
- Type: Tektur (headings, Google Fonts) · Tonos Mono Variable (text; needs an Adobe Fonts kit or an embedded file) · IBM Plex Mono fallback.
- Scroll: native sticky pins, no scroll hijacking; everything collapses to final states with `prefers-reduced-motion`.
- Tools in the page footer: Brief (design notes per version), Notes, Mobile 390, Reduce motion.
