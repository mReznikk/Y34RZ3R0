# «Проявка» v10: change spec (27 Oct 2026)

1. **Nothing black on black.** Now white: redaction bars, the censor bar on «репрессивное», the strike line, the shirt and fragment icons, the Parepin window frame and address bar, ≠ box borders, listen rules, byte borders, ghost outlines, the sound-wave baseline. The ≠ boxes fill blue at «=»; Gesamtkunstwerk blocks are white outlines. `font-synthesis:none`.
2. **Type (final):** headings stay in **Tektur**; all other text in **Tonos Mono Variable** (Adobe Fonts), falling back to IBM Plex Mono.
   - Tonos Mono is not on Google Fonts. It shows when installed locally, when its file is embedded in the `@font-face "YZ Mono"` rule, or via an Adobe Fonts kit `<link>` on this GitHub Pages site (the kit must allow this domain).
   - An unused `@font-face "YZ Heading"` rule (Heading Now, dropped) can be deleted.
