# «Проявка» v33: change spec (27 Oct 2026)

1. **Tab title:** «Year Zero» (no «Проявка»).
2. **Responsive pass** (checked at 360, 390, 820, 1440 and 2560 px wide):
   - Type scales with the screen: body `clamp(16px, .55vw + 10px, 26px)`, small text `clamp(11px, .32vw + 6.9px, 17px)`, headings up to 210px (was capped at 112px). Unchanged at 1440; about a third larger on a 2560 monitor.
   - Phones: display lines get line-height 1.02–1.1 instead of .88–.94, so wrapped headings no longer touch; the four readers, the ≠ sequence and its boxes get phone-sized type.
   - Chapter titles «Повредить картинку» / «Последний носитель» are fitted by the width of the actual text (the slipped half no longer shrinks them to the minimum on phones or pushes them off the edge on big screens).
3. **Proofreading** (requested by the author; changes the article text):
   - «Перыая» → «Первая»; «проотиворечит» → «противоречит»; «Что нужно было сделать чтобы» → «…сделать, чтобы»; «В фрагменте» → «Во фрагменте»; «СД диск / поверхность СД» → «CD-диск / поверхность CD»; «В марте 2007 года, Генри Дженкинс» → no comma; «адрес - ещё» → «адрес — ещё»; «По официальной версии –» → «—»; «все еще» → «всё ещё»; «недалеком», «отдаленная» → «недалёком», «отдалённая»; «…антиутопия становится» → «…антиутопия, становится»; «Даже … песни тоже названы» → «Даже … песни названы»; «А именно попытку» → «А именно — попытку».
   - «Пройти по ссылке, сопоставить документы или изображения, найти скрытое сообщение погружает слушателя на время занять положение…» → «…найти скрытое сообщение — всё это заставляет слушателя на время занять положение…».
   - Quotes made consistent: «улики», «мультимедиа», «„снимками“ жизни…».
   - **No hanging prepositions:** a non-breaking space after one- to three-letter prepositions, conjunctions and particles (в, на, с, к, у, о, и, а, но, по, за, из, от, до, не, для, при, без, под, что, как…) and before dashes, across all visible text. The word-by-word animations keep such pairs together.
