# «Проявка» v17: change spec (27 Oct 2026)

1. **Fewer scroll glitches.** The scroll-driven bursts from v16 are toned down: one short 3-frame burst every ~750–1200px of travel (4 frames when scrolling quickly), at most one per second. Chapter-change and end-of-page bursts are unchanged.
2. **Image slots wired to files.** Every image placeholder has a `data-img` path in `img/`. If the file exists it replaces the placeholder (cover-cropped, placeholder texture and labels hidden); if not, the placeholder stays. The Another Version of the Truth top layer is drawn from `img/avott-a.jpg` (still erasable); the bottom layer uses `img/avott-b.jpg`. 17 files in total — names, places and proportions are listed in `img/README.md`.
3. Scratch counter no longer breaks if an image can't be read back from the canvas (falls back to an estimate of the erased area).
