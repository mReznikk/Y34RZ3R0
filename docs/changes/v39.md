# «Проявка» v39: change spec (28 Oct 2026)

Body and small type now scale in proportion to the screen above 1440 px. Laptops and phones are unchanged.

Problem: on big monitors the headlines grew with the viewport (up to 170–520 px), but captions, labels and mono text stayed at 11–15 px, and some buttons at a fixed 10.5 px. The text became unreadable next to the headlines.

- `--b` → `max(clamp(16px, .55vw + 10px, 26px), 1.25vw)`: 18 px at 1440, 24 at 1920, 32 at 2560.
- `--s` → `max(clamp(11px, .32vw + 6.9px, 17px), .8vw)`: 11.5 px at 1440, 15.5 at 1920, 20.5 at 2560.
- All 69 fixed sizes from 9.5 to 20 px → `max(Npx, N/14.4 vw)`. Each one equals its old value at 1440 and grows proportionally above it.
- The CD byte grid: `max-width: max(980px, 68vw)`, so the larger bytes keep the same arrangement.

Checked at 1440 (identical to before), 1920 and 2560: no horizontal overflow.
